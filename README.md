## Цель задания
Реализация адаптивного веб-интерфейса интернет-магазина с использованием фреймворка Bootstrap и создание легковесного веб-сервера на чистом Python (`socket`) для обработки сетевых запросов.

---

## Изменения и выполненные задачи

### Верстка и фронтенд:
* **Главная страница (`home.html`)**: Создана базовая структура с двухколоночным макетом.
* **Каталог и категории (`catalog.html`, `category.html`)**: Реализована адаптивная сетка карточек товаров (4 в ряд) с использованием встроенных компонентов Bootstrap.
* **Всплывающее меню пользователя**: Настроен рабочий `Dropdown` компонент для профиля в нижней части меню.
* **Контакты (`contacts.html`)**: Сверстана страница обратной связи с формой отправки данных и информационным блоком.

###  Бэкенд на чистом Python:
* **Многофункциональный TCP-сервер (`main.py`)**: Написан сервер на низкоуровневых сокетах без использования сторонних фреймворков.
* **Обработка GET-запросов**: Сервер корректно считывает HTML-файлы через контекстный менеджер `with open()` и возвращает их браузеру с заголовком `Content-type: text/html`.
* **Поддержка статики**: Реализована динамическая отдача CSS-файлов с корректным MIME-типом `text/css`, что позволило полностью запустить стили Bootstrap локально.
* **[Доп. задание] Обработка POST-запросов**: Сервер успешно принимает данные формы контактов, парсит тело запроса и выводит полученную информацию от пользователя в консоль.

---

## Как протестировать проект локально:
1. Склонировать репозиторий и переключиться на ветку `feature/bootstrap-interface`.
2. Запустить файл `src/main.py`.
3. Открыть в браузере страницу `http://127.0.0.1:5000`.
4. Заполнить форму на странице контактов и нажать «Отправить» — данные отобразятся в консоли запущенного сервера.
